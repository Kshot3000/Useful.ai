Subscription audit

Paste the charges from a statement. Each line is turned into a yearly figure with the multiplier shown. The cancellation note is a script you send, not a rule about how long a merchant has to stop billing.

  1. 01
    Type or paste what the statement actually charged. A yearly plan looks small per month until it is written as a year.
  2. 02
    Set your own flag line if you want. This page does not publish a “too expensive” cutoff.
  3. 03
    Copy the script for the ones you are ending. Confirmation number and cancel path stay blank until you fill them.

Each line: name, amount, then weekly, monthly, quarterly, or yearly. If the cadence word is missing, the line is treated as monthly and marked as assumed.

Yearly figures use ×52, ×12, ×4, or ×1. That is arithmetic on this page, not the merchant’s billing calendar. A weekly charge ×52 can differ from 365 days of billing.
