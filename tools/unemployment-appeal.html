After the determination

Unemployment appeal packet

Appeal windows are on the notice, and they are not the same in every state. Type the number of days the notice gives you. This page dates the packet, keeps the determination number next to the hearing list, and does not state a benefit amount.

  1. 01
    Copy the determination number and the mailing date exactly as printed. If the notice counts from receipt instead, use the date you actually received it.
  2. 02
    Type the appeal window in days from that notice, or from the workforce-agency page it cites. Leave it blank if you have not checked.
  3. 03
    File the way the notice says — portal, mail, or fax. This page drafts the request. It does not file it.

Example fills names only. The day count stays blank so a sample does not look like a deadline.
