Security deposit timeline

The deadline in days is yours to look up, on the legislature site or in the lease. This page only counts from the move-out date you enter, then writes the demand and keeps the photo log next to it.

  1. 01
    The start date is the day possession and keys went back, unless the lease or statute uses a different trigger. Confirm which one applies before you rely on the date.
  2. 02
    Read the return deadline on an official page. Type that number. Do not guess from a forum.
  3. 03
    Send the letter the way that source requires. Certified mail is common. It is not universal. This page will not pretend it is.
