Type what the order charged and what actually arrived. This page subtracts the gap and writes a letter. It does not look up a return window, a cooling-off period, or a card dispute deadline.

    Copy the order number, the charge, and the date off the receipt or the statement. Leave a field blank if you have not confirmed it.
  2. 02
    Log each item: what you ordered, what arrived, and the amount on that line. This page does not estimate a price.
  3. 03
    If a return or reply period is printed on the receipt or the policy page you opened, type those days. Leave them blank if you have not confirmed one.
